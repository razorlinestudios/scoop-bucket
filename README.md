# Razorline Studios Official Scoop Bucket

Official [Scoop](https://scoop.sh) bucket for **Razorline Studios Ltd** Windows desktop apps.

## Quick Start

```powershell
scoop bucket add razorline https://github.com/razorlinestudios/scoop-bucket
scoop install razorline/rigcheck
```
